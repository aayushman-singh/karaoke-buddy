# 30-Second Demo Script

0:00 - Open KaraokeBuddy and show the recent videos library.

0:04 - Click a saved karaoke track to resume it with its previous settings.

0:08 - Drag Song key down two semitones while the video keeps playing.

0:14 - Raise Silence the singer to reduce guide vocals without changing tempo.

0:20 - Click Save this version and accept the default `~/Videos/KaraokeBuddy/` folder.

0:26 - Show the exported MP4 in the saved location, ready to rehearse or share.

Reviewer takeaway: KaraokeBuddy turns any karaoke video into a singer-ready version without making users learn audio tooling.
